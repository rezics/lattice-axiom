# 採用領地優先、群系驅動、約束求解的世界生成

## 背景與問題

Lattice Axiom 希望同時支援無限世界、跨大量區塊的結構、可由模組擴充的群系，以及日後加入的地質、水文、文明與工業系統。若讓所有內容共享一組固定環境向量並以區間挑選群系，模組可以宣告重疊區間，增加向量維數也不能從數學上消除衝突；群系也會退化為對既有環境的分類標籤，而不能主導自身地貌、氣候與生態。

另一方面，若每個群系直接寫入最終方塊，河流、岩層、山脈、含水層與洞穴又會在群系邊界失去連續性。世界生成因此需要同時保存內容主權與跨領地的不變條件。

## 決策

Lattice Axiom 的世界生成採用以下方向：

1. 世界生成是世界種子、座標與可識別生成輸入的確定性查詢；各輸入由自身套件、能力與演算法修訂獨立版本化，不依賴全域世界版本，也不依賴鄰近區塊先生成或後生成。
2. 先建立不帶氣候語義的多尺度空間領地圖譜，再為領地指定群系；不以固定環境向量作為群系註冊槽位。
3. 群系以穩定識別碼參與與註冊順序無關的加權仲裁，不依靠載入順序、可碰撞數值 ID 或模組專屬地理區域解決衝突。
4. 群系是可執行的環境定義程式：它輸出地形、氣候、水文、地質、生態、資源、氣氛與其他通道的目標場、約束或生成能力。
5. 河流、岩層、地形密度與其他必須跨群系連續的系統由通用求解器整合各模組意圖；群系不任意覆寫不受治理的最終方塊。
6. 不同生成能力透過有型別的通道、依賴關係與合成規則組成生成圖，而不是依賴一條所有遊戲都必須使用的硬編碼流程。
7. 官方內容與第三方內容使用同一套領地、欄位、計畫與約束介面。
8. 世界保存目前已解析設定檔與產物級生成記錄；模組增刪、演算法升級與既有產物遷移必須沿實際依賴子圖顯式處理，不能用單一 `worldVersion` 默默改寫未生成區域。

## 決策範圍

本決策確定責任方向與組合模型，但不確定下列細節：

- 空間領地圖譜最終採用哪一種 Voronoi、冪圖、網格或扭曲方式。
- 領地尺度、權重治理與邊界寬度的預設值。
- 各輸出通道的完整型別與合成代數。
- 洞穴是群系內部能力、獨立生成層，或共享拓撲加群系形態的混合形式；此項後由[決策 0002](0002-hybrid-cave-generation-composition.md)確定為混合形式。
- 河流、侵蝕、地質與文明模擬採用何種具體演算法。

以上內容由[可組合世界生成架構](../architecture/world-generation.md)繼續細化；[決策 0003](0003-no-global-version-package-scoped-compatibility.md)修正版本與閉包粒度，[決策 0004](0004-territorial-delegation-for-spatial-generation.md)修正地形和洞穴的領地委派，洞穴責任分界另見[可組合洞穴生成架構](../architecture/cave-generation.md)。

## 考慮過的選項

### 固定環境向量選擇群系

優點是容易理解，也能快速實作連續氣候分布。缺點是任何有限維空間都允許兩個模組宣告相同區域；新增維度只能改變表達能力，不能提供衝突仲裁。這也把群系限制為環境分類結果。

### 每個模組擁有獨立地理區域

可以隔離模組內部群系，但會使套件邊界變成世界邊界，並導致權重稀釋、領地截斷和不同規模內容包之間的分配問題。

### 群系直接產生全部最終內容

最大化群系自主性，卻無法自然維持跨群系水文、地質、地形與大型結構的連續性，也會讓多個系統爭奪同一方塊。

### 本次採用的混合方向

領地所有權由統一仲裁決定；群系定義環境意圖；通用約束求解器產生連續結果。這使群系保持語義主權，同時讓世界級規律成為可驗證的不變條件。

## 後果

### 正面

- 群系數量不需要預先分配固定槽位。
- 註冊順序不影響結果，衝突有明確仲裁語義。
- 群系具有真正的範圍、中心、邊界、鄰接與內部座標。
- 地質、文明、結構和洞穴可以作為能力加入同一生成圖。
- 跨區塊與平行生成可由座標查詢和有界影響範圍支援。

### 負面

- 必須為每種輸出通道設計合成規則，不能依賴通用的「最後寫入者獲勝」。
- 產物級生成記錄、缺失模組、資料遷移與舊新規劃域接縫成為必要產品功能。
- 全域連續性求解必須保持可局部查詢，演算法設計比單純噪聲分類複雜。
- 無預設註冊上限不代表無限運算資源；實際載入的模組集合仍是有限資料結構。

## 驗證方式

第一個領地原型至少要證明：

1. 打亂註冊順序不改變輸出。
2. 相同種子、座標與相關產物依賴子圖得到相同結果；不相關模組變更不使產物失效。
3. 加入候選群系只改變由新候選贏得的領地。
4. 領地沒有未定義區域，邊界可查詢且過渡連續。
5. 一千個合成群系下仍能在可接受時間內建立、查詢與快取領地。
6. 相鄰區塊以任意順序或平行生成時，地形、水系與結構計畫保持一致。

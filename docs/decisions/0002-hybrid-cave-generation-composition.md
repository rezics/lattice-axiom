# 決策 0002：洞穴採共享拓撲與群系形態的混合組合模型

> 本決策的混合責任模型仍然生效；[決策 0004](0004-territorial-delegation-for-spatial-generation.md)把「每維度唯一主幹」修正為「每拓撲所有權域唯一提供者、每維度唯一協調器」。

## 背景

「洞穴演算法應放在群系內部，還是作為獨立生成層」把數個不同責任壓成了同一個問題。洞穴至少同時包含：地下語義領地、跨區域連通拓撲、局部幾何形態、地質與水文約束，以及生態和玩法內容。

若全部交給群系，各模組會重複處理連通性，跨群系洞穴也容易在區塊或領地邊界斷裂。若全部交給獨立洞穴層，群系又可能退化成洞穴完成後才貼上的材質與裝飾標籤，無法真正定義自身環境。

此外，「可組合」不等於所有生成器都能對同一密度場無條件相加。有些通道需要合併，有些需要選出唯一所有者，有些則必須經預算和空間仲裁。

## 決策

採用「共享拓撲、群系決定形態、正交系統提供約束」的混合模型。

1. 地下群系是空洞產生前就存在的三維語義領地，而不是事後依洞壁方塊反推的標籤。它可以發出洞穴意圖，描述希望出現的洞室、通道、垂直度、尺度與內容需求。
2. 洞穴拓撲是獨立且可替換的能力。它負責跨規劃格的節點、邊、共享入口、可達性與連通約束，不決定最終洞壁風格。
3. 每個維度只選用一個 `CaveTopologyCoordinator`；每個由維度或地下群系擁有的拓撲域只選用一個 `CaveTopologyProvider`。子領地可以接管完整局部拓撲，但不能同時疊加多個互不協調的主要所有者。
4. 主幹之外允許任意數量的有界貢獻者提交支洞、洞室、裂縫、目的地與修改意圖；它們必須經過空間仲裁、預算與確定性排序。
5. 地下群系可以接管領地內的完整拓撲與形態。父域以入口、水文連接、保護體積和預算委派子域；邊界形態可以混合，但拓撲必須遵守共享入口、最小淨空和可達性契約。
6. 地質與水文是正交語義提供者。它們可以約束拓撲和形態，例如岩性、斷層、地下水位、壓力與地下河去向，而不擁有全部洞穴生成責任。
7. 洞穴內容主要由地下群系與目的地模組提供；拓撲層只保留路徑、容量、入口與玩法節點等必要語義。
8. 核心內容與第三方模組使用相同的註冊、仲裁、診斷和版本契約。

## 通道基數與合成規則

| 通道 | 基數 | 預設合成規則 |
| --- | --- | --- |
| `cave.coordinator` | 每維度唯一 | `SelectOne`：選出領地委派與跨域約束協調器 |
| `cave.topology` | 每拓撲所有權域唯一 | `TerritorialDelegation`：最具體領地接管，否則繼承父域預設 |
| `cave.intent` | 多個 | `BudgetedMerge`：在區域預算內合併群系與模組意圖 |
| `cave.branch` | 多個 | `SpatialArbitration`：依空間宣告、衝突類型與穩定鍵仲裁 |
| `cave.morphology` | 局部唯一或邊界多個 | `TerritoryWinner`／`BoundaryBlend` |
| `cave.destination` | 多個 | `PlannedPlacement`：先規劃目的地，再把連接需求交給拓撲 |
| `cave.constraint` | 多個 | `ConstraintSet`：地質、水文與玩法限制共同求解 |
| `terrain.density` | 多個有界場 | `SmoothCSG`：只在已核准的空間包絡內合成 |

因此，可組合性的單位是「帶有基數、契約和仲裁規則的通道」，不是任意演算法的數值相加。

## 主要資料流

```text
地表群系領地 ─────┐
地下群系領地 ─────┼─> Cave Intent ─> Cave Topology Coordinator
地質／水文語義 ───┘                         │
                                             ├─> 共享圖、入口與連通約束
                                             ├─> 群系形態與材質實現
                                             ├─> 生態、資源與目的地內容
                                             └─> 有界 Density／SDF 合成
```

## 結果

- 跨群系洞穴可以維持連續，群系仍能真正定義洞穴的形狀、材質、生態和玩法氣質。
- 維度預設拓撲與各地下群系的局部拓撲都可替換；替換作用域由領地委派明確限制。
- 多模組衝突可以按通道診斷，不再只看到最終密度場中的不明破洞。
- 系統必須維護拓撲與幾何之間的雙向驗證：圖上可達不代表實際網格一定可通行。
- 地下群系領地、水文和洞穴拓撲的求解順序將比單一雕刻器更複雜，需要規劃格快取與回歸測試。

## 未在本決策固定的細節

- 第一批 `CaveTopologyProvider` 採圖搜尋、方向場、生長模型或其他演算法。
- 地下群系領地是否直接沿用地表 `Territory Atlas` 的資料結構，或只共用仲裁協定。
- 洞穴預算的單位，以及支洞、洞室、含水層和目的地之間如何換算成本。
- 地表群系、地下群系與地質體在不同深度的影響權重。
- 入口契約中的水壓、流體狀態與跨規劃格水文連續性細節。

## 被否決的簡化方案

### 每個群系忽略父域契約自行生成洞穴

群系可以生成完整局部拓撲，但若不接受入口委派、保護體積與水文約束，仍會破壞跨領地、跨區塊和跨模組的連續性。

### 先生成所有洞穴，再貼地下群系標籤

這使地下群系無法影響拓撲需求與幾何性格，只能做材質和裝飾後處理。

### 所有洞穴生成器直接合併密度場

這沒有每域唯一所有者、空間委派與預算語義；生成器數量增加時，連通性、性能和可解釋性都會失控。

## 後續工作

- 在[洞穴生成架構](../architecture/cave-generation.md)中定義資料契約與原型切片。
- 為共享入口、實際淨空、可達性和流體連續性建立自動驗證。
- 用同一組種子比較純雕刻、純群系與混合模型的連通性、局部辨識度和生成成本。

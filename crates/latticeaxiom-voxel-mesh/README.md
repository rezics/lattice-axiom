# latticeaxiom-voxel-mesh (milestone 3)

Placeholder. In-house voxel meshing: visible-face culling and greedy merging
over chunk voxel array views, natively following ADR 0011 (Z-up faces and
winding). Algorithms reference block-mesh-rs (MIT OR Apache-2.0, unmaintained
since 2022); ported fragments keep attribution and a third-party notice.
Pure data-to-data; no renderer or world-model dependencies.

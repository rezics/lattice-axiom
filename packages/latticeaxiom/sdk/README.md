# `@latticeaxiom/sdk`

Owns `latticeaxiom-abi`, `latticeaxiom-render-contracts`, `latticeaxiom-runtime-contracts`, `latticeaxiom-sdk-macros`, `latticeaxiom-sdk`.

Implementation entry and membership are declared in `latticeaxiom-package.toml`.
Public APIs and tests are maintained beside the code.

[Author-owned package interfaces](docs/package-interfaces.md) records the
accepted direction for source APIs, portable boundaries, scoped bindings and
package-defined frameworks. Its current-evidence table distinguishes existing
SDK/ABI foundations from pending package-to-package activation and loader work.
